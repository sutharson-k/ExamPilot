# ExamPilot 🚀
> **AI Exam Preparation Planner**

ExamPilot helps students create personalized, adaptive study schedules, organize revision checklists, review uploaded PDF notes, and test their knowledge with practice questions.

---

## ✨ Features

- 📅 **Dynamic Study Timetable**: Automatically allocates study hours proportionally across upcoming exam dates and subject difficulty levels.
- ⚡ **Smart Rescheduling (Automatic Adjustment)**: If you miss a scheduled session, ExamPilot automatically recalculates remaining workloads and redistributes missed hours to future available days.
- 📚 **Study Materials & PDF Reader**: Upload, manage, and read lecture slides, past question papers, and PDF notes directly in the app.
- ✅ **Revision Checklist**: Track subject-by-subject topics with interactive subtasks and completion progress counters.
- 🧠 **Practice Questions**: Built-in 80+ question bank across Mathematics, Physics, Chemistry, Biology, Computer Science, English, History, and Economics with instant score feedback and detailed explanations.
- 💾 **Local Storage Persistence**: All plans, uploads, and progress are saved safely in your browser.
- 🚀 **One-Click Startup**: Launch with `start.bat` which automatically handles dependencies and opens your browser.

---

## 🛠️ Stack

- **Frontend**: Vanilla HTML5, CSS3, JavaScript (ES6+)
- **Icons & Fonts**: Font Awesome 6, Google Fonts (Inter & Poppins)
- **Local Server**: Lightweight Node.js HTTP server
- **Storage**: Browser LocalStorage & File API

---

## 🚀 Quick Start

### Option 1: One-Click (Windows)
Double-click `start.bat` in the project root directory. It will install requirements if needed and launch the app in your default browser.

### Option 2: Manual
```bash
npm install
npm start
```
Then visit `http://localhost:3000`.
